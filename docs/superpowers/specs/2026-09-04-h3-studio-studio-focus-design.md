# H3 Studio「Studio Focus」界面重设计

**状态：设计已确认，待实现前审阅**
**日期：2026-09-04**

## 1. 目标与范围

H3 Studio 现有界面已覆盖 H3 Standard、FastH3 VSA、MiniMax Music3、首尾帧、多模态参考、超分与历史任务，但创作页面把输入模式、服务、画幅、实时预览和高级参数并列展示，首屏信息密度过高。

本次重设计的目标是让“描述并生成视频”成为唯一主路径，并把不需要每次调整的配置改为可扫读、可展开的摘要。功能、默认值、工作流 JSON、API 和服务能力保持不变。

不在本次范围内：新增推理能力、修改 ComfyUI 工作流、变更服务端接口、改变历史超分的能力或结果格式。

## 3. 信息架构

### 3.1 主路径

```
提示词 → （按需）输入条件 → （按需）运行参数 → 生成视频 → 右侧预览 / 历史结果
```

桌面端采用 62 / 38 的双栏工作区：

- 左栏为创作面：标题、提示词、条件与参数摘要、唯一主按钮。
- 右栏为结果面：实时预览开关、空/生成中/完成状态、结果操作与简短的最近生成入口。
- 历史画廊保留在工作区下方，不与创建动作争夺首屏注意力。

900px 以下改为单栏，保留“先创作、后预览、再历史”的阅读顺序。移动端使用 16px 页面边距，所有可点击行与开关的实际点击区域不小于 44px。

### 3.2 渐进披露

三类高频但非必改参数默认收起，并始终显示当前摘要：

| 区域 | 默认摘要 | 展开内容 | 特殊行为 |
| --- | --- | --- | --- |
| 视频输入模式 | `纯文本`、`首尾帧 · N 张素材` 或 `多模态参考 · N 项` | 模式选择、首尾帧上传或参考素材 | 切换到首尾帧/多模态后自动展开；上传完成后允许收起 |
| 运行参数 | `H3 Standard · 1344 × 768 · 5 秒 · 6 步` | 服务、画幅、时长 | FastH3 仍只显示其已验证的 832 × 480；Music3 显示自身运行参数 |
| 精细设置 | 当前预设、步数或优化组合摘要 | 采样器、种子、推理预设与优化开关 | 沿用现有 `showAdvanced` 状态和全部能力判断 |

展开触发器是语义化 `button`，带 `aria-expanded` 和清晰的区域标签。用户无须展开区域也能看见当前会影响输出的服务、画幅、时长和关键输入条件。

### 3.3 实时预览

TAEH3 不再作为生成参数区中的独立大卡片。它移动到右侧预览区标题行的最右端，表现为紧凑的“TAEH3 实时预览”开关：

- 仅在 H3 Standard 且服务能力可用时显示并可操作；不可用时显示已有原因。
- 继续绑定原有 `form.taeH3Preview`，不改变请求字段。
- 生成中的预览图、进度和“非最终画质”说明仍显示在结果面，不弱化状态信息。

## 4. 视觉系统

### 4.1 设计令牌

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--surface-canvas` | `#0B0D12` | 页面底色，真深色而非蓝灰渐变 |
| `--surface-raised` | `#131720` | 编辑面、预览面、展开内容 |
| `--surface-hover` | `#1A1F2A` | 行悬停与轻量选中背景 |
| `--ink-strong` | `#F0F2F7` | 标题与主要正文 |
| `--ink-muted` | `#94A0B5` | 帮助文本、摘要标签 |
| `--accent-warm` | `#E3C77A` | 主要按钮、选择状态和极少数强调 |
| `--border-subtle` | `rgba(240,242,247,.12)` | 分隔与控件轮廓 |
| `--radius-panel` | `12px` | 面板、输入框、折叠行 |
| `--motion-fast` | `180ms` | hover、焦点、图标反馈 |
| `--motion-panel` | `240ms` | 折叠内容进入与离开 |

字体延续本地优先的中文 UI 字体链；数值、尺寸、步数和时间使用现有等宽字体。避免加载在线字体，保证本地/离线部署稳定。

### 4.2 容器与排版

- 顶栏高度约 56px，仅保留品牌、当前服务/连接状态与必要操作。
- 移除大面积营销 Hero；首屏标题为紧凑的“创建视频”，辅助文案不超过一行。
- 创作与预览各为一块目的明确的面，不再嵌套多层玻璃卡片。
- 折叠行使用左侧轻量线性图标、主标题、单行摘要和右侧 SVG chevron；摘要用颜色和文案共同表达状态。
- 图标统一为约 1.5px 的圆角描边 SVG，不使用 Emoji 作为结构性图标。

### 4.3 动效与可访问性

- hover、按下、焦点和状态变更使用 `opacity`、`transform` 与简短 easing；不使用循环背景动画。
- 折叠内容以短暂淡入/纵向位移建立空间连续性；`prefers-reduced-motion` 下禁用非必要过渡。
- 可见的键盘焦点环、文字与背景至少满足可读对比；图标按钮提供 `aria-label`。
- 生成、停止、上传和超分的错误/禁用/加载状态保持现有语义和恢复路径。

## 5. 组件与数据边界

### 5.1 App 组合层

`src/App.tsx` 继续拥有 `form`、连接能力、生成状态与上传状态。新增只影响展示的局部 UI state：

- `inputModeOpen`
- `runSettingsOpen`

它们不进入生成请求，也不写入历史。切换到需要素材的输入模式时，`inputModeOpen` 自动为真。

### 5.2 复用的披露组件

新增一个轻量、受控的披露组件（名称以实现为准），统一承载：标题、摘要、图标、`aria-expanded`、内容区和 chevron。它避免在 App 与 GenerationControls 中复制交互和样式。

### 5.3 输入模式

App 中现有的输入模式按钮和 `ReferenceInputs` 保留数据逻辑：

- 折叠头显示由 `form.inputMode` 与上传素材数量推导出的摘要。
- 展开区继续渲染现有纯文本/首尾帧/多模态参考选择与 `ReferenceInputs`。
- `referenceCapability` 的禁用、原因提示和上传中的禁用逻辑不变。

### 5.4 运行参数与高级设置

`GenerationControls` 重组为：

1. 受控“运行参数”披露区：现有推理服务、输出画幅、时长。
2. 现有“精细设置”披露区：采样器、种子、优化开关、FastH3/Music3 专有设置。

所有 `onChange` 补丁、服务能力判断和 FastH3/Music3 规则继续复用。不会改变 H3 兼容预设、FastH3 固定画幅、Turbo 锁定步数或服务端校验。

### 5.5 预览区

`GenerationPanel` 接收 TAEH3 所需的最小新增 props：当前值、能力和变更回调。它在预览标题/工具区显示开关，保持现有 job、停止、重试、超分和历史媒体行为不变。

## 6. 错误处理与兼容性

- 已有服务不可用、上传失败、停止失败、超分不可用和工作流错误文案均保持。
- 折叠只影响可见性，不得卸载已上传素材或重置表单值。
- 小屏幕不得出现横向滚动；长摘要在必要时换行或截断并保留完整可访问名称。
- 鼠标、键盘和触控均可展开/收起并操作所有已存在的功能。

## 7. 验收与测试

### 功能

- 纯文本、首尾帧、多模态参考三种输入模式均可切换；首尾帧和参考素材在折叠后仍保留。
- H3 Standard、FastH3 VSA、MiniMax Music3 的切换规则、能力禁用和默认值保持。
- 画幅、时长、采样步数和优化设置继续写入同一 `GenerationForm`。
- TAEH3 开关从预览区改变后，提交请求带正确字段。
- 生成、停止、超分及历史复用的原有路径不回归。

### 视觉与交互

- 1440 × 1024：主创作区、预览区、默认折叠和展开态与三张设计稿一致。
- 390 × 844：无横向滚动，按钮/开关触控区足够，摘要不遮挡主按钮。
- 浏览器控制台无相关 error/warn；无 Vite 错误遮罩。
- `prefers-reduced-motion: reduce` 下无不必要动效。
