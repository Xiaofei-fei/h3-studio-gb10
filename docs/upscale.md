# 视频增强与超分

增强是生成完成后的独立任务。原始 H3 生成、FlashVSR 和 RealESRGAN 各有自己的状态、停止接口和可用性检查；停止增强不会通过结束 ComfyUI 或整机 GPU 进程实现。

## 从界面使用

在当前会话的“历史作品”中打开已完成视频。满足 worker capability 和尺寸要求时，卡片会显示“2K 稳定增强”操作。完成后的原始视频和增强版本都可在预览中选择与下载。

历史视频也支持增强，但必须仍是 ComfyUI output 目录内可安全引用的 MP4。Music3 音频结果不能进入视频增强流程。

增强任务与生成任务串行保护：存在未结束的 H3 生成任务时不能启动；同一源视频已有未结束的增强任务时不能重复创建。

## RealESRGAN：默认稳定路径

RealESRGAN worker 使用 `RealESRGAN_x2plus.pth`、FP16 推理和重叠 tile。它先验证模型 SHA-256 和可用系统内存，再允许任务进入队列。当前只开放两个端到端验证过的 2K 输出规格：

| 原始 H3 视频 | 输出规格 |
| --- | --- |
| 832 × 480 | 2560 × 1478 |
| 1280 × 720 | 2560 × 1440 |

worker 会检查输出尺寸、帧数和帧率；源视频包含音频时，编码阶段会保留音频流。它不承诺任意分辨率、任意编码器或 4K 路径。

运行时内存不足、模型不存在或 hash 不匹配时，`/api/health` 会把稳定增强标为不可用。不要通过替换模型文件绕过校验。

## FlashVSR：条件开放的高质量路径

FlashVSR 是独立的 worker，适合明确标注为离线高质量的尝试。它需要单独的私有运行时、模型资产和 GPU 兼容性验证。部署阶段会检查源码、运行时、模型安装和小型推理；任何一项失败都会写入兼容性状态，BFF 只显示失败原因，不会把不稳定路径暴露为可用。

gate 通过后，worker 返回它实际支持的 `2k` / `4k` 目标。不要根据 UI 文案假设两种目标一定存在；以 `/api/health` 的 `flashVsr` capability 为准。

FlashVSR 会验证输出的尺寸、帧率、帧数，并在源视频有音频时要求输出保留音频。它的 GPU 子进程被单独跟踪，取消只影响当前 FlashVSR 任务。

## 停止和恢复

- 生成视频：在生成面板点击停止。BFF 先尝试从队列删除等待任务，正在执行的任务则向 ComfyUI 请求中断。
- 增强视频：在历史卡片或增强状态区点击“停止超分”。worker 将任务置为 `cancelling`，清理仅属于该任务的未发布临时输出。
- 页面刷新后：可通过 BFF 的增强状态接口继续读取任务快照；不应假定浏览器内存就是唯一真实状态。

如果任务长期停在 `cancelling`，先查看对应 worker 日志和 BFF 日志；不要首先重启 ComfyUI 或删除 output 目录。常见诊断命令见[故障排查](troubleshooting.md)。
